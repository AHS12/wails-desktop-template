# Changelog

What's new in each version.

## 0.1.0 (November 21, 2026)

**A starting point**

- A desktop app with the parts every app needs sooner or later, already working: saving to a
  library and to files, autosave, undo, backups to a file, a folder or the cloud, Recently
  removed, updates, the tray, settings, a command palette and a tour.
- An example app that keeps notes, to replace with your own.
- Runs on Windows, on a Mac, and on Linux, with a .deb, .rpm, Arch package and AppImage.
